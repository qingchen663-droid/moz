## 环境坑（别再踩）

- `.bat` 只能纯 ASCII；含中文的 `.ps1` 必须 UTF-8 **带 BOM**，否则路径静默变坏。
- Git Bash 会吃掉 `/c` 和 `/tmp`；需要时 `MSYS_NO_PATHCONV=1`。
- 控制台打中文要 `PYTHONIOENCODING=utf-8`。
- Qoder 内置浏览器面板没点开时，截图/点击必失败 → 用 `evaluate_script` + `node --check` 代替。
- 后端是 `--reload`：改 .py 会重启，**内存里的当天额度/静默状态会清零**；自测脚本别假设进程连续。
- 中转慢（25~35s）且偶发连接失败：先怀疑网络，再怀疑代码。

## 必须更正我上一轮的结论：中转看图**不稳定**，不是"能看图"

上一轮我用红/绿/蓝三张纯色图测，三次全对，于是写"推翻旧结论，能看图"。**那个结论只在当时的时间窗成立。**
01:50 重测同一批图（外加 4 组格式对照）：

- 红 PNG → "我这边收到的是一张纯白的图"
- 橙 JPEG → **空回复**（一个 token 都没有）
- 橙 PNG → "一片纯白，没图案"
- 蓝 JPEG → "一片纯白"

请求格式是对的（`data:image/...;base64,` 完整、text 非空，`图片请求格式契约` 快检守着），
所以是**中转侧把图片丢了**，而模型在被丢图时会照着编。00:35 那批"全对"和 01:50 这批"全白"是同一个代码。

产品结论：**不要把"能看图"当承诺**。目前 `runtime_model_config.json` 里 `multimodal: true` 是用户自己勾的，
先留着，但界面文案不该说"我会看图内容"。明天要做的：

1. 附件按钮的 tooltip 与提示改成不承诺的措辞（现在是"上传图片，我会看图内容"）。
2. `selftest --full` 里的 `中转看图能力` 探针只报 warn，别当失败——它是环境问题。
3. 想彻底确认就多点几次探针，看命中率再决定要不要在界面上提示"这个中转看图不稳"。
